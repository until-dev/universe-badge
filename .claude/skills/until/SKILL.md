# until

This repository tracks its work in Until: Tickets are outcomes, Tasks are the steps a person does, and Jobs are the steps one agent finishes in one session.

Before you plan or work on Until Tickets or Jobs, run:

```bash
untl brief
```

and follow what it prints. For one Job, run `untl brief JOB` for that Job's brief.

The instructions come from the installed `untl`, so they always match its commands. This skill only points to them.
